Homepage information architecture

Search-first directories feel lighter because they postpone the long link graph.

Yelp and Tripadvisor-style entry pages usually make search the main action, expose only a few popular choices, then move deep browsing to category, city, result, and footer pages. Your current homepage is useful, but it shows too much of the site architecture at once.

Current pattern

Directory portal homepage

Strong for crawl paths, but visually heavy and less like a mainstream directory entry page.
